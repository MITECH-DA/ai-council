# AI 자문위원회

최대 8개의 AI 페르소나가 하나의 안건을 놓고 순차적으로 토론하고, 사회자가 마지막에 종합 정리하는 서비스입니다.
- 사업가: 시장 기회, 매출 성장, 경쟁 우위, 실행 속도 관점에서만 발언합니다. 
- 전략가: 시장 규모, 경쟁 구도, 전략적 옵션 비교, 프레임워크 기반 사고방식으로만 발언합니다. 
- 사모펀드 M&A 담당: 밸류에이션, 딜 구조(지분/자산 인수, 마일스톤 페이아웃 등), 시너지, 엑싯 전략 관점에서만 발언합니다. 
- 재무전문가: ROI, 현금흐름, 손익분기점, 기회비용 관점에서만 발언합니다. 
- 법무사: 계약 리스크, 인허가/컴플라이언스, 책임소재 관점에서만 발언합니다. 
- 오픈이노베이션 담당: 외부 기술 스카우팅, 공동개발/제휴 모델 설계, 협업 생태계 적합성 관점에서만 발언합니다.
- 스타트업 네트워크 전문가: 해외 스타트업 생태계 접근성, 잠재 파트너·인수 후보 소싱, 네트워크 레버리지 관점에서만 발언합니다. 
- 리스크매니저: 실패 시나리오, 운영 리스크, 컨틴전시 플랜 관점에서만 발언합니다. 

## 준비물

- Claude API 키 (`sk-ant-`로 시작, 필요 시 https://console.anthropic.com 에서 발급)


## 최초 접속

1. 페이지 접속 (https://mitech-da.github.io/ai-council)
2. 상단 "Claude API 키" 입력창에 키 붙여넣기
   - 다른 브라우저나 기기에서는 재입력 필요

## 회의 진행

1. "회의 안건" 칸에 검토하고 싶은 안건을 구체적으로 작성
   - 예: `A사와 국내 독점 유통 계약 체결 여부 검토`
2. "라운드 수" 선택
   - 1라운드: 빠른 의견 취합
   - 2라운드(기본값): 상호 반박 포함
   - 3라운드: 심층 토론 / 동일한 의견이 반복 표출될 수 있습니다.
3. "참석자" 선택
   - 회의를 진행하고자 하는 참석자를 체크(클릭)합니다.
   - 최대 8명까지 선택 가능
4. "첨부 파일" 추가 (필요시)
   - 토론 내에서 참고할 수 있는 첨부 파일을 추가합니다.
   - 텍스트, 이미지, PDF, Word, PPT, Excel 파일을 첨부 가능합니다.
   - Word, PPT, Excel의 경우 텍스트만을 추출하여 토론에 활용하므로, 문서 내 이미지가 포함되어 있다면 PDF로 변환하여 첨부하면 더 정확한 결과가 나옵니다.
5. "회의 시작" 클릭
   - 선택한 라운드 수만큼 참석자들이 자동으로 발언합니다.
   - 완료되면 사회자가 종합 정리합니다.
6. "텍스트로 내보내기" 클릭
   - 회의록 내용을 텍스트 파일로 다운로드 받을 수 있습니다.

## 결과 확인

- "회의록" 영역에 발언이 순서대로 누적 표시됨
- 좌석 카드는 현재 발언 중인 역할이 강조 표시됨
- 마지막 "사회자 종합"에 참석자들의 핵심 입장, 이견 지점, 권고안이 정리되어 나옴

## 유의사항

- **안건이 구체적일수록 결과 품질이 좋습니다. 막연한 주제는 막연한 답변으로 이어집니다.**
- 2라운드 기준 완료까지 약 1~2분 소요됩니다. 진행 중 새로고침하면 회의 내용이 사라집니다.
- 본인 API 키를 직접 입력해서 쓰는 개인용 도구입니다. API 키를 불특정 다수와 공유하지 마세요.
