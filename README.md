# AI 자문위원회 데모

사업가 · 재무전문가 · 법무사 · 리스크매니저, 4개의 AI 페르소나가 하나의 안건을 놓고 순차적으로 토론하고, 사회자가 마지막에 종합 정리하는 웹 데모입니다.

## 준비물

- Claude API 키 (https://console.anthropic.com 에서 발급, `sk-ant-`로 시작)
- 배포된 페이지 URL (GitHub Pages로 배포 후 생성됨)

## 최초 접속

1. 페이지 접속
2. 상단 "Claude API 키" 입력창에 키 붙여넣기
   - 이후 이 브라우저에는 자동 저장되어 다시 입력할 필요 없음
   - 다른 브라우저나 기기에서는 재입력 필요

## 회의 진행

1. "회의 안건" 칸에 검토하고 싶은 안건을 구체적으로 작성
   - 예: `A사와 국내 독점 유통 계약 체결 여부 검토`
2. "라운드 수" 선택
   - 1라운드: 빠른 의견 취합
   - 2라운드(기본값): 상호 반박 포함
   - 3라운드: 심층 토론, 시간 소요 큼
3. "회의 시작" 클릭
   - 사업가 → 재무전문가 → 법무사 → 리스크매니저 순으로 자동 발언
   - 완료되면 사회자가 종합 정리

## 결과 확인

- "회의록" 영역에 발언이 순서대로 누적 표시됨
- 좌석 카드는 현재 발언 중인 역할이 강조 표시됨
- 마지막 "사회자 종합"에 4명의 핵심 입장, 이견 지점, 권고안이 정리되어 나옴

## 유의사항

- 안건이 구체적일수록 결과 품질이 좋습니다. 막연한 주제는 막연한 답변으로 이어집니다.
- 2라운드 기준 완료까지 약 1~2분 소요됩니다. 진행 중 새로고침하면 회의 내용이 사라집니다.
- 본인 API 키를 직접 입력해서 쓰는 개인용 도구입니다. URL을 불특정 다수와 공유하지 마세요.
- 이 레포에는 API 키를 절대 커밋하지 마세요. 키는 각자 브라우저의 localStorage에만 저장됩니다.

## 배포 방법 (GitHub Pages)

1. 이 레포의 `index.html`을 유지한 채 push
2. Settings → Pages → Source를 `main` 브랜치 `/(root)`로 설정
3. 1~2분 후 `https://<계정명>.github.io/<레포명>/`에서 접속 가능
